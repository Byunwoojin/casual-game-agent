# Puzzle Pals — 캐릭터 100개 AI 생성 프롬프트

**사용법**:
1. https://www.bing.com/create 로그인
2. 아래 프롬프트를 한 줄씩 복사 → 입력 → Generate
3. 4장 중 마음에 드는 것 다운로드
4. 파일명을 ## 옆 영문명으로 변경 (예: `apple.png`, `cat.png`, `ice_cream.png`)
5. 100개 다 모이면 `Assets/Sprites/Characters/_Source/` 폴더에 모두 복사
6. Unity 메뉴: `PuzzlePals > Import Character Art (Auto Name Match)` 클릭

**일관된 스타일 핵심**: 모든 프롬프트가 같은 style suffix 사용 (`cute kawaii flat icon, simple thick outline, pastel colors, ...`).

## 진행 후 단계

1. 위 100개 다운로드 후 파일명 정리:
   - `apple.png`, `cat.png`, `ice_cream.png`, `polar_bear.png`, `mermaid_cat.png` 등
   - 띄어쓰기 → 언더스코어 (`Ice Cream` → `ice_cream`)
2. `Assets/Sprites/Characters/_Source/` 폴더에 모두 복사
3. Unity 메뉴: **`PuzzlePals > Import Character Art (Auto Name Match)`**
4. 다이얼로그에 매칭/할당 결과 표시 — 매칭 안 된 파일은 rename 후 재실행
5. Play → 진짜 아트로 100레벨 진행
