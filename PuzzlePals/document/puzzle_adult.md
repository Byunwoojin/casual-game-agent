## 1. 퍼즐 조각 생성 규칙 (핵심)

### 1.1 핵심 원칙: "조각 형태 = 위치 힌트"

40-60대 타겟 유저가 **조각 형태만 보고도 대략적인 위치를 추론**할 수 있어야 합니다.

```
예시:
┌──────────────────────┐
│ ┌──┐              ┌──┐│
│ │평│  ... 보드 ... │평││
│ └──┘              └──┘│
│                       │
│  ... 중앙 조각 ...   │
│                       │
│ ┌──┐              ┌──┐│
│ │평│              │평││
│ └──┘              └──┘│
└──────────────────────┘

평 = 평면 (가장자리)
```

### 1.2 조각 형태 분류 (4가지)

#### 🔲 A. 모서리 조각 (Corner Pieces) - 4개

```
좌상단:  ┌─●        우상단:  ●─┐
        │                      │
        ●                      ●

좌하단:  ●          우하단:    ●
        │                      │
        └─●                  ●─┘
```

**특징:**
- **두 면이 평면** (직선)
- 반드시 모서리 4곳에만 존재
- 유저가 **가장 먼저 찾아 맞추는 조각**
- 시각적으로 즉시 구별 가능

#### 🔳 B. 가장자리 조각 (Edge Pieces)

```
상단 가장자리:  ────────
              ●      ●  (한 면만 평면)
               ╲    ╱

하단/좌/우도 유사
```

**특징:**
- **한 면만 평면**
- 보드의 4개 변을 따라 배치
- 모서리 다음으로 찾기 쉬움

#### 🧩 C. 내부 조각 (Interior Pieces)

```
    ●
   ╱ ╲
  ●   ●  (사방이 굴곡진 요철)
   ╲ ╱
    ●
```

**특징:**
- **사방이 모두 요철(돌기/홈)**
- 보드 중앙 영역에 위치
- 가장 어려운 배치 (색상·패턴으로만 구분)

#### ✨ D. 특수 조각 (Special Pieces - 선택)

```
- 비정형 조각 (불규칙한 모양)
- 2-3조각이 이미 붙은 조각 (Easy 모드 힌트용)
```

### 1.3 조각 생성 알고리즘

```python
# 의사 코드

def generate_puzzle_pieces(image, rows, cols):
    pieces = []
    
    for row in range(rows):
        for col in range(cols):
            piece = create_piece()
            
            # 1. 위치 결정
            if (row, col) in CORNERS:
                piece.type = "corner"
                piece.flat_sides = [적절한 2면]
            elif row == 0 or row == rows-1 or col == 0 or col == cols-1:
                piece.type = "edge"
                piece.flat_sides = [적절한 1면]
            else:
                piece.type = "interior"
                piece.flat_sides = []
            
            # 2. 요철 생성
            for side in piece.non_flat_sides:
                piece.protrusion[side] = random_choice([
                    "convex",  # 돌기 (볼록)
                    "concave"  # 홈 (오목)
                ])
                # 중요: 인접 조각과 짝 맞추기
                # 한 조각이 convex면 인접은 concave
            
            # 3. 이미지 자르기
            piece.image = crop_with_mask(image, piece.shape)
            
            pieces.append(piece)
    
    return pieces
```

### 1.4 조각 크기 & 그리드

**핵심 철학**: 조각 수가 레벨마다 치솟아 유저가 지치는 구조를 피한다. **32 / 64 두 값만 반복 사용**하고, 체감 난이도는 **이미지의 구성 복잡도** (인물 수·디테일 밀도·색 변화)가 담당한다.

#### 32조각 (가벼운 세트)
- 그리드 예: 4×8 (landscape) / 6×6 (square) — 이미지 비율에 맞춰 선택
- 조각 크기 (모바일, 1080w 기준): 약 150×150px
- 모서리 4개 / 가장자리 12~20개 / 내부 8~16개

#### 64조각 (집중 세트)
- 그리드 예: 8×8 (square) / 6×11 (portrait) / 7×9 (landscape) — 비율 최적화
- 조각 크기 (모바일): 약 100×100px
- 모서리 4개 / 가장자리 24~28개 / 내부 32~36개

#### 이미지 난이도 버킷 (UX 카테고리)
조각 수와 별개로, 레벨 선택 화면에서 그룹 라벨·배경색으로 5단계 구분:
`Very Easy · Easy · Medium · Hard · Very Hard`

→ 실제 레벨 매핑은 §4.1 참고.

### 1.5 조각 뱅크 정렬 옵션 (중요!)

유저가 쉽게 찾을 수 있도록 **정렬 기능 필수**:

```
조각 뱅크 정렬 메뉴:
├── 🔲 모서리 먼저 (Easy 기본값)
├── 🔳 가장자리 먼저
├── 🎨 색상별 그룹
├── 🔀 랜덤 (Hard 기본값)
└── 🔍 검색 (핀치 줌으로 특정 조각 찾기)
```

### 1.6 시각적 단서 강화

**조각 뱅크에서 조각 구별 돕기:**

```
모서리 조각: 🔲 배경에 옅은 노란 테두리
가장자리 조각: 🔳 배경에 옅은 파란 테두리
내부 조각: 🧩 기본 배경

(설정에서 on/off 가능, 기본 ON)
```

### 1.7 스냅 & 피드백

**조각이 올바른 위치에 근접할 때:**

1. **5px 이내 진입**: 조각 테두리 녹색 빛남 (0.3초)
2. **정확한 위치**: "딸깍" 사운드 + 햅틱 진동
3. **자동 스냅**: 부드러운 애니메이션으로 정위치 이동 (0.2초)

**잘못된 위치에 놓으려 할 때:**

1. 조각이 살짝 떨리며 원래 위치 근처로 돌아감
2. 소리는 나지 않음 (실패 사운드는 좌절감 유발)
3. 조각은 조각 뱅크가 아닌 **드래그 시작 위치**로 복귀

## 2. 완성 플로우 (Win Condition)

### 2.1 완성 감지

```
[마지막 조각이 올바른 위치에 배치됨]
    ↓
[모든 조각이 올바른 위치인지 검증]
    ↓
[완성 확정]
    ↓
[시퀀스 시작]
```

### 2.2 완성 시퀀스 (4단계)

#### 🎬 Step 1: 완성 순간 (0.5초)

```
효과:
- 마지막 조각 탁! 하고 맞춰지는 강한 햅틱 진동
- 퍼즐 전체 테두리가 순간 황금빛 빛남
- 효과음: "띠링~" (상쾌한 완성음)
```

#### 🎆 Step 2: 이미지 리빌 (1.5초)

```
효과:
- 조각 경계선이 서서히 사라짐 (페이드 효과)
- 완성된 이미지가 매끄럽게 드러남
- 부드러운 배경 음악 (2-3초)
- 황금빛 파티클 효과 (선택)
```

#### 🎉 Step 3: 완성 화면 전환 (참고 게임 벤치마크)

```
┌────────────────────────────────┐
│                                │
│       [녹색 방사형 배경]        │  ← 승리의 느낌
│                                │
│                                │
│         🎉 레벨 N 완료!        │  ← 큰 타이틀
│                                │
│                                │
│    ┌──────────────────┐       │
│    │                  │       │
│    │  [완성 이미지]    │       │  ← 중앙 강조
│    │  (퍼즐 경계 희미) │       │
│    │                  │       │
│    └──────────────────┘       │
│                                │
│                                │
│   ⭐⭐⭐  (별점 표시 - 선택)   │
│                                │
│                                │
│    ⏱ 12분 34초                 │
│    💡 힌트 2회 사용             │
│                                │
│                                │
│   ┌──────────────────────┐    │
│   │     계속하기          │    │  ← 1개 버튼 (심플)
│   └──────────────────────┘    │
│                                │
└────────────────────────────────┘
```

**참고 게임 디자인 포인트:**
- **녹색 방사형 배경** (성취감의 심볼)
- **큰 흰 글씨** "레벨 N 완료!" (40-60대 가독성)
- **중앙 이미지**만 깔끔하게 (부가 정보 최소화)
- **단일 버튼** "계속하기" (선택 스트레스 없음)

#### 🏠 Step 4: 메인 화면 복귀 + 해금

```
[계속하기 탭]
    ↓
[메인 화면으로 부드러운 전환 (0.5초)]
    ↓
[해금 애니메이션 재생]
```

### 2.3 효과음 상세

| 단계 | 사운드 | 길이 | 볼륨 |
|---|---|---|---|
| 마지막 조각 스냅 | "탁" (강한 타격음) | 0.2초 | 강 |
| 완성 감지 | "띠링~" (마법 차임) | 1.0초 | 중 |
| 별점 획득 | "반짝!" (3번 연속) | 1.5초 | 중 |
| 완성 화면 BGM | 부드러운 승리 멜로디 | 3-5초 | 약 |
| 계속하기 탭 | "딸깍" (클릭음) | 0.1초 | 약 |

**사운드 파일 권장:**
- Royalty-free 소스: Freesound.org, Zapsplat
- 파일 형식: OGG (용량 작음) 또는 MP3
- 샘플레이트: 44.1kHz, 16bit

**설정 연동:**
- 설정 > 사운드 ON/OFF 전역 적용
- 효과음 볼륨 / BGM 볼륨 개별 조절

### 2.4 햅틱 피드백 패턴

| 단계 | 패턴 | 강도 |
|---|---|---|
| 일반 조각 스냅 | 단일 (15ms) | 약 |
| 마지막 조각 스냅 | 단일 (50ms) | 강 |
| 완성 감지 | 3연속 (30ms × 3) | 중 |
| 별점 획득 | 패턴 (짧-짧-길) | 중 |

**iOS 햅틱**: `UIImpactFeedbackGenerator` 활용  
**Android 햅틱**: `VibrationEffect.createOneShot()` 활용

### 2.5 진행 중 축하 & 광고 타이밍

#### 중간 축하 (In-Level Milestones, L1 제외)

| 시점 | 연출 | 사운드 |
|---|---|---|
| 진행률 **50%** | 화면 중앙 "절반 완성 ✨" 토스트 (1.5초 페이드) + 작은 파티클 버스트 | 짧은 반짝 SFX |
| 진행률 **75%** | 화면 중앙 "거의 다 왔어요" 토스트 + 중간 파티클 | 짧은 반짝 SFX |
| **가장자리 전부 완성** | 보드 외곽이 금색 라인으로 한 번 빛남 + 토스트 "테두리 완성" | 경쾌한 차임 |

**L1은 중간 축하 연출 없음** — 첫 레벨은 조작 학습에 집중시키기 위함 (몰입 방해 방지).

#### 광고 타이밍

| 시점 | 광고 종류 | L1 | L2~L20 |
|---|---|---|---|
| 레벨 시작 전 (로딩 시) | Interstitial | ❌ | ✅ |
| 레벨 완료 후 (Complete → 메인 복귀) | Interstitial | ❌ | ✅ |
| 일일 힌트 2회 소진 후 추가 요청 | Rewarded Video | 레벨 무관 적용 | 레벨 무관 적용 |

**L1 보호 정책**: 첫 레벨은 학습·몰입이 목적이므로 강제 광고(Interstitial)를 일체 배치하지 않는다. L2부터 레벨당 최대 2회(시작/완료) 노출.

**Rewarded Video**는 유저가 명시적으로 "광고 보고 힌트 받기"를 선택할 때만 재생 — 강제성 없음.

## 3. 해금 시스템 (Unlock)

### 3.1 해금 규칙

#### 순차 해금 (참고 게임 방식)

```
레벨 1 → 완료 시 → 레벨 2 해금
레벨 2 → 완료 시 → 레벨 3 해금
...
레벨 N → 완료 시 → 레벨 N+1 해금
```

**장점:**
- 단순·직관적
- 진행도 명확
- 40-60대에게 부담 없음

**단점:**
- 특정 이미지가 싫으면 막힘
- 건너뛰기 불가

#### 대안: 혼합 해금 (선택)

```
초반 10개: 순차 해금 (튜토리얼 역할)
11번 이후: 3개 완료할 때마다 카테고리 전체 해금
```

### 3.2 해금 애니메이션 (참고 게임 벤치마크)

이미지 3에서 본 패턴을 그대로 반영:

```
[메인 화면 복귀 직후]
    ↓
[방금 완료한 퍼즐 카드]
  → 색감 유지
  → 우측 하단에 ✅ 체크 마크 페이드 인 (0.5초)
    ↓
[다음 퍼즐 카드]
  → 흑백 → 컬러로 전환 (1.0초, 부드럽게)
  → 자물쇠 아이콘이 딸깍 열리며 사라짐
  → "Play" 버튼이 통통 튀며 등장 (bounce 효과)
  → 조각 수 배지(64) 페이드 인
    ↓
[카드 자체가 살짝 흔들리며 주목 유도] (선택)
```

### 3.3 카드 상태 시각화

| 상태 | 썸네일 | 아이콘 | 하단 정보 |
|---|---|---|---|
| **🔒 잠금** | 흑백 + 반투명 | 자물쇠 🔒 | 레벨 번호 (예: 3) |
| **🆕 신규 해금** | 컬러 + 반짝임 | 조각 수 (64) + "NEW" 태그 | Play 버튼 |
| **▶ 진행 중** | 컬러 | 조각 수 | Play + 진행률 (11%) |
| **✅ 완료** | 컬러 | ✅ 체크 | 별점 ⭐⭐⭐ |
| **🔁 다시 플레이** | 컬러 | "Replay" | 최고 기록 표시 |

### 3.4 진행률 표시 (참고 게임의 "11%")

```
진행률 계산:
  = (맞춘 조각 수 / 총 조각 수) × 100%

표시 위치:
  카드 우측 상단, 흰 둥근 배지

표시 규칙:
  - 0% → 배지 숨김 (NEW 태그만)
  - 1-99% → "N%" 표시
  - 100% → ✅ 체크 마크로 교체
```

### 3.5 완료 상태 세부

완료된 퍼즐도 **다시 플레이 가능**:

```
완료된 퍼즐 카드 탭 시:
┌──────────────────────────────┐
│                              │
│   이미 완료한 퍼즐입니다      │
│                              │
│   🏆 최고 기록               │
│   ⏱ 10분 23초                │
│   💡 힌트 0회                 │
│   ⭐⭐⭐                      │
│                              │
│   ─────────────────────     │
│                              │
│   [다시 플레이]               │
│   [난이도 변경]               │  ← Easy→Medium 등
│   [취소]                      │
│                              │
└──────────────────────────────┘
```

### 4.3 일일 퍼즐 (Daily Puzzle)

메인 화면 상단 파란 배너:

**특징:**
- 매일 새로운 한정 퍼즐

- 연속 N일 달성 시 특별 보상
- 지난 일일 퍼즐은 월간 캘린더에서 재플레이 가능

## 5. 보상 시스템

### 5.1 별점 획득 조건

| 조건 | 별점 |
|---|---|
| 완성 | ⭐ (기본) |
| 힌트 2회 이하 + 시간 내 완성 | ⭐⭐ |
| 힌트 0회 + 시간 내 완성 | ⭐⭐⭐ |

**시간 기준 (Easy 48조각):**
- ⭐⭐⭐: 10분 이내
- ⭐⭐: 15분 이내
- ⭐: 시간 무제한

### 5.2 코인·힌트 획득

```
완성 보상:
├── ⭐: 기본 코인 10개
├── ⭐⭐: 20개 + 힌트 1개
└── ⭐⭐⭐: 50개 + 힌트 3개 + 배지

일일 퍼즐 완성:
└── 50코인 + 힌트 2개

연속 N일 달성:
├── 3일: 힌트 3개
├── 7일: 힌트 7개 + 특별 배지
└── 30일: 프리미엄 테마 해제
```

### 5.3 업적 배지 연동

완성 시점에 배지 획득 조건 자동 체크:

```
완성 직후:
  ↓
[배지 획득 조건 체크]
  ↓
획득 시:
  [배지 획득 팝업] 
  "🏆 새 배지 획득: 첫 퍼즐 완성!"
  [확인]
  ↓
없으면:
  [바로 완성 화면으로]
```

### 5.4 힌트 시스템 (일일 리프레시 + Rewarded Ad)

**기본 규칙:**
- **하루 2회 무료** 힌트 (매일 자정 0시 리셋, 디바이스 로컬 시간 기준)
- 2회 소진 후 추가 힌트 요청 시 **Rewarded Video 광고** 시청 필수 (레벨·난이도 무관)
- 별점 보상·일일 퍼즐·연속 출석으로 받은 힌트는 별도 적립 (§5.2 참고) — 즉시 사용, 일일 상한 미적용
- IAP 구매 힌트는 즉시 적립 (제한 없음)

**힌트 효과:**
- 남은 조각 중 1개의 정답 Snap Zone이 0.5초간 금색 깜빡임
- 해당 조각이 Piece Bank에서 금색 테두리로 강조
- 유저가 직접 드래그해 맞춰야 소진 (자동 스냅 아님)

**UI:**
- 상단 헤더에 💡 × N 표시 (N = 오늘 남은 무료 힌트 수 + 보너스 힌트)
- N=0 상태에서 💡 탭 → "광고 보고 힌트 받기" 모달
- 모달 버튼: "지금 보기 / 취소" 2개만 (선택 스트레스 최소화)

**저장 키 예시:**
```json
{
  "daily_hint_count": 2,
  "daily_hint_reset_date": "2026-04-22",
  "bonus_hints": 5,
  "rewarded_ads_today": 0
}
```
